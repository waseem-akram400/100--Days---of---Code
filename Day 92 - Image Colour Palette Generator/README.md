# Day 92 - Image Colour Palette Generator

A Python Tkinter app that extracts up to eight representative colours from an image.

## Features
- Choose a local image.
- Display colour swatches and HEX codes.
- Copy a HEX code to the clipboard.
- Save the palette to a text file.

## Install
python -m pip install -r requirements.txt

## Run
python main.py
