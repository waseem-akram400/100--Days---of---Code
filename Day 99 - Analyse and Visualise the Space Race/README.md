# Day 99 - Analyse and Visualise the Space Race

## Project
Historical space mission data analysis using Python, Pandas, Matplotlib and Seaborn.

## Install
python -m pip install -r requirements.txt

## Run
python main.py

## Outputs
- charts/01_missions_per_year.png
- charts/02_top_organisations.png
- charts/03_mission_outcomes.png
- charts/04_missions_by_month.png
- charts/05_launch_locations.png (when location data is available)
- cleaned_space_missions.csv

The first run attempts to download a public dataset and requires an internet connection.
