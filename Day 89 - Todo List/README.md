# Day 89 - Todo List

A personal task manager built with Python and Flask.

## Features
- Add new tasks
- Mark tasks complete or incomplete
- Delete tasks
- View total, remaining and completed task counts
- Save tasks between restarts using a JSON file

## Run

```powershell
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.

The tasks.json data file is created when the first task is saved.
