# Day 75 - Time Series Data Visualization

Practice project using Pandas and Matplotlib.

Topics:
- Exploring Google Search interest data
- Cleaning and converting timestamps
- Resampling time-series data by month
- Tesla and Bitcoin line charts
- Date locators and date formatters
- Line styles and markers
- Unemployment charts and grids
- Rolling averages to smooth data

IMPORTANT: All included CSV data is illustrative practice data, not official market, Google Trends, or unemployment records.

## Run
python -m pip install -r requirements.txt
python main.py
