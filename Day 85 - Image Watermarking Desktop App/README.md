# Day 85 - Image Watermarking Desktop App

A desktop application built with Python, Tkinter and Pillow.

## Features
- Open an image from your computer
- Enter custom watermark text
- Choose watermark position
- Adjust text size and opacity
- Preview the watermark
- Save a new watermarked image

## Run
Install the dependency:

python -m pip install -r requirements.txt

Start the app:

python main.py

The original image is not overwritten unless you deliberately select its
filename in the save dialog. It is recommended to save a new copy.
