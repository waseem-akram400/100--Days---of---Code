# Day 78 - Movie Data Analysis

This beginner project practices:
- Data cleaning with Pandas
- Investigating zero-revenue movies
- Filtering international movies with multiple conditions
- Seaborn bubble charts and regression plots
- Converting years into decades with floor division
- Linear regression with scikit-learn

The project generates a small **synthetic sample dataset** if `data/movies.csv` does not exist. It is for practice, not the original course dataset.

Run:
1. `python -m pip install -r requirements.txt`
2. `python main.py`

Results and charts are saved in the `output` folder.
