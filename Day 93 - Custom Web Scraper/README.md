# Day 93 - Custom Web Scraper

A Python desktop app that collects a webpage title, headings, and links,
then saves the results as a CSV file.

## Install dependencies
python -m pip install -r requirements.txt

## Run
python main.py

Use this tool only on webpages you are permitted to access.
Respect website terms, robots.txt guidance, rate limits, and access restrictions.
This basic scraper does not execute JavaScript.
