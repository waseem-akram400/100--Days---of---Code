# Day 84 - Tic Tac Toe

A two-player Tic Tac Toe game made with HTML, CSS and JavaScript.

## Files

- index.html: the game board and controls
- style.css: layout, colours and responsive design
- script.js: turns, win detection, draw detection and scores

## Run the game

Open index.html in a web browser. No installation is required.

## How to play

1. Player X starts.
2. Players take turns selecting an empty square.
3. Three matching marks in a row, column or diagonal win.
4. Play Again starts another round and keeps the scores.
5. Reset Scores clears the scores and starts a new round.
