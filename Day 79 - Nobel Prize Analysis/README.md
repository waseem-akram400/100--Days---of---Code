# Day 79 - Nobel Prize Data Analysis

Practice project covering:
- Cleaning data with Pandas
- Plotly bar and donut charts
- Matplotlib trends over time
- Plotly choropleth world map
- Sunburst regional breakdown
- Laureate age analysis

The included CSV is a small synthetic sample for learning, not the complete official Nobel dataset.

Run:
1. `python -m pip install -r requirements.txt`
2. `python main.py`

Interactive Plotly charts are saved as HTML files in `output/`.
