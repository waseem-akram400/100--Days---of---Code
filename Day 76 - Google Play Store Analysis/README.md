# Day 76 - Google Play Store Analysis

Practice project using Pandas and Plotly.

Topics:
- Removing NaN values and duplicate rows
- Exploring app ratings, reviews, and size
- Converting installs, size, and price to numeric values
- Pie and donut charts
- Bar charts and scatter plots
- Stacking grouped data
- Grouped bar charts and box plots

IMPORTANT: The included CSV contains synthetic practice data, not the original Google Play Store dataset.

## Run
python -m pip install -r requirements.txt
python main.py

Interactive charts are saved as HTML files in the charts folder.
Open any HTML chart in your browser to explore it.
