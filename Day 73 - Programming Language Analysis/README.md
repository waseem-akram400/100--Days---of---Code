# Day 73 - Programming Language Data Analysis

This project practices:
- Reading CSV files with Pandas
- Exploring and cleaning data
- Converting strings into timestamps
- Grouping and pivoting DataFrames
- Visualizing data with Matplotlib
- Multi-line time-series charts
- Moving averages to smooth data
- Comparing the first and latest values

IMPORTANT: The included CSV is synthetic practice data, not the original course dataset.

## Run
python -m pip install -r requirements.txt
python main.py

Charts are saved in the charts folder.
