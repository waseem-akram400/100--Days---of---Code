# Day 88 - Cafe and WiFi Website

A Flask website for discovering and adding cafes with Wi-Fi, power sockets, coffee ratings, opening hours and map links.

## Run

```powershell
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.

Cafe information is stored in cafes.csv, which is created automatically.
