
# Day 58 - TinDog Website

Angela Yu's 100 Days of Code Python Bootcamp.

## Project
A responsive startup landing page for TinDog.

## Technologies
- HTML5
- CSS3
- Bootstrap 5

## Features
- Hero section
- Website features
- Testimonial
- Partner companies
- Three pricing plans
- Responsive layout

## How to Run
Open `index.html` in a web browser.

Note: An internet connection is needed for the Bootstrap CDN and online images.
