# Day 98 - Custom Automation

A beginner-friendly browser automation project using Python and Selenium.

## Requirements
- Python
- Google Chrome
- Internet connection on first run may be needed for Selenium Manager

## Install
python -m pip install -r requirements.txt

## Run
python main.py

The program opens a local practice form, fills the name and email,
submits it, checks the success message, and closes the browser.
