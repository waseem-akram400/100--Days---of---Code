# Day 83 - Portfolio Website

A responsive personal portfolio website built with HTML5 and CSS3.

## Files

- index.html: website content and page sections
- style.css: colours, layout, cards and responsive styling

## Run the website

1. Open this folder in PyCharm.
2. Open index.html.
3. Right-click the file and select Open in Browser.

No Python packages or web server are required.

## Personalise it

- Check the About section and update the description if needed.
- Add or remove project cards to match your actual work.
- Replace the LinkedIn link with your own profile URL.
