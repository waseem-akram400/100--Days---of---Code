# Day 80 - Handwashing Analysis

Practice topics:
- Explore and clean hospital data
- Compare yearly results by clinic
- Calculate mortality rates
- Compare periods before and after handwashing
- Visualize distributions with Seaborn
- Run Welch's t-test using SciPy

Important: The CSV is a synthetic teaching dataset, not the original historical Vienna hospital data.

Run:
1. `python -m pip install -r requirements.txt`
2. `python main.py`

Charts and summary CSV files are saved in `output/`.
