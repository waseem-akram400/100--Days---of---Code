# Day 74 - LEGO Data Analysis

Practice project using Pandas and Matplotlib.

Topics:
- Exploring LEGO sets and colors
- Finding oldest and largest sets
- Counting sets by year
- Using Pandas agg()
- Comparing measures with separate chart axes
- Scatter plots
- Merging sets and themes using keys
- Creating bar charts

The included data is synthetic practice data, not the original course dataset.

## Run
python -m pip install -r requirements.txt
python main.py
